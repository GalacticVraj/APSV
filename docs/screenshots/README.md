## Tips

- Use **1280×800** or **1440×900** browser window for consistent width
- Dark mode is default — no need to change anything
- For `/facility-command`, pick any facility from the `/facilities` card grid first
- For `/copilot`, type a query like *"Which facility has the highest shadow price?"* before capturing
